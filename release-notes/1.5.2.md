Log every song played on your PC with the date and time it was heard. Made for internet radio, and it works with any player.

## Install

1. Download **radiolog-1.5.2.zip** below (or *Source code (zip)*) and unzip it.
2. **Windows:** double-click `install.bat`. **Linux / macOS:** run `./install.sh`.
3. Open a **new** terminal and run `radiolog show`. The first start asks where to keep your song history and downloads.

Already using an older version? Unzip over the old folder and run the installer again. Your history, downloads and settings are kept.

## What's new since v0.1

**Recording and history**
- Full date and time for every song, plus a `── Discovered ──` heading in `watch`
- Songs are numbered (`#12`) in `show`, so you can pick them

**Search and download**
- `radiolog search 12`: open the song in a YouTube, YouTube Music or Spotify search
- `radiolog download 12`: download with yt-dlp in the best quality available (original stream, no re-encoding, with cover art and tags)
- `--video` for the best video joined with the best audio (`.mkv`)
- **Batch download**: `download 3 5 8-12`, `download --today`, `download --since 3h`, or select several in `pick`
- **Audio formats**: `radiolog config --format best | opus | m4a | mp3`
- `radiolog pick`: an interactive menu to search or download one or many songs

**Setup and settings**
- First-time setup asks where to store your song history and your downloads, with a check that the location doesn't need administrator rights
- `radiolog config` shows and changes all settings (`--db`, `--downloads`, `--format`, `--reset`)
- The installer can install Python and ffmpeg for you on Windows

## Fixes in 1.5.2
- Downloads were reported as **done** even when YouTube's search found nothing. radiolog now checks the file exists, retries with a simpler search, and otherwise says "Not found on YouTube".
- Cover art couldn't be embedded into `.opus` files (missing helper module), so downloads were reported as failed and left `.png`/`.webp` files behind. Fixed, and those leftovers are now cleaned up.
- Leftover cover images no longer make a song count as "already downloaded".
