**This release exists to test `radiolog update`.** It contains no new features.

If you're reading this in your terminal after running `radiolog update`, the update check works. 🎉

## How to test

1. With **1.6.1** installed, run `radiolog update`.
2. It should show this text and ask: *Update radiolog to 1.6.2 now?* Press Enter.
3. **Windows:** a new window opens, waits a moment, installs, then says *radiolog 1.6.2 is installed*. Close it and open a new terminal.
4. Run `radiolog --version`. It should say **radiolog 1.6.2**.
5. Run `radiolog update` again. It should say you already have the latest version.

## Small improvement
- Version comparison now understands four-part versions (e.g. 1.6.2.1), so quick follow-up fixes are detected as updates.
