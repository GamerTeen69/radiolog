Log every song played on your PC with the date and time it was heard. Made for internet radio, and it works with any player.

## New: update from the terminal

From now on, updating radiolog is one command:

```
radiolog update            # check, show what's new, ask, then update
radiolog update --check    # only check for a new version
radiolog --version         # show your installed version
```

- It checks GitHub for the newest release, shows what's new and installs it after you confirm.
- Your song history, downloads and settings are kept.
- On Windows the update finishes in a new window a moment after radiolog closes, because a running program can't replace itself.

## Install or update

This is the last time you need to update by hand:

1. Download **radiolog-1.6.1.zip** below and unzip it (over the old folder if you're updating).
2. **Windows:** double-click `install.bat`. **Linux / macOS:** run `./install.sh`.
3. Open a **new** terminal.

After that, future versions install with `radiolog update`. See the [README](https://github.com/GamerTeen69/radiolog#readme) for the full guide.
